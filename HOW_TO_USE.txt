【このパッケージについて】
本アイテムは Steam Workshop サブスクライブ用の配布パッケージです。

【起動方法】
1. このフォルダ内にある「run_zTranzlator.cmd」をダブルクリックしてください。
   初回起動時に必要な準備が自動で行われ、そのままGUIアプリが立ち上がります。
   （※ Pythonのインストールや環境変数の設定は一切不要です）
   （※ 2回目以降は準備なしで0秒即起動します）

2. 画面の指示に従って翻訳したいMODを選択し、
   「一括AI翻訳を実行」->「ローカルMOD適用」をクリックするだけで、
   完全非破壊の日本語化パッチMODが自動生成されます。

【PZ本体・MODが未検出と表示される場合 (v1.1.0新機能)】
・別ドライブや別SSDにSteamをインストールしている場合も全自動で検出されますが、
  万が一画面上部に「● PZ: 未検出」と表示された場合は、そこをクリックして
  Project Zomboid 本体のフォルダを選択してください（設定は自動保存されます）。

【動作環境】
・OS: Windows 10 / 11 (64-bit)
・推奨GPU: NVIDIA GeForce GTX 1660 / RTX 2060 / RTX 3060 以上 (VRAM 6GB〜8GB以上)
  ※ 本ツールは Ollama によるAI文脈翻訳を主軸としています。
  ※ GPU性能が控えめな場合でも、Google Gemini（無料API）などのクラウドAIモードが利用可能です。

[English]
How to Launch:
1. Simply double-click "run_zTranzlator.cmd" inside this folder!
   All required files are automatically prepared on first launch.
   (No Python or manual environment setup required).

2. Select your target mod in the suite, run AI translation,
   and apply the generated standalone patch mod to your local game.

If "PZ: Not Found" Appears:
- The suite automatically scans all drives and Steam libraries. If your install
  path is not detected, simply click "PZ: Not Found (Click to set)" on the top
  header to select your Project Zomboid directory. It will be permanently saved.

Requirements:
- Windows 10 / 11 (64-bit)
- Recommended GPU: GTX 1660 / RTX 2060 / RTX 3060+ (6GB-8GB+ VRAM for Ollama)
  (Google Gemini free API cloud mode is also available).
